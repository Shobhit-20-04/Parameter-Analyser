# Parameter Analyser

Parameter Analyser is a PHP-based web application designed to analyze and evaluate various parameters from a given dataset. This project provides insights into data trends, allowing users to make informed decisions.

## 🚀 Features

- **Data Processing**: Reads and processes structured data.
- **Parameter Evaluation**: Analyzes key parameters for better insights.
- **Report Generation**: Outputs results in a readable format.
- **User-Friendly Interface**: Simple and intuitive to use.

## 📌 Requirements

- WAMP/XAMPP Server
- PHP 7 or higher
- MySQL Database
- Web browser (Chrome, Firefox, Edge, etc.)

## 🛠 Installation & Usage

### 🔹 Running Locally Using WAMP/XAMPP:

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Shobhit-20-04/Parameter-Analyser.git
   ```
2. **Move the project folder to your local server's root directory:**
  ```sh
  C:\wamp64\www\parameter-analyser
  ```
  **or for XAMPP:**
  ```sh
  C:\xampp\htdocs\parameter-analyser
  ```
3. **Start Apache and MySQL in WAMP/XAMPP**

4. **Database Setup:**
  - Open phpMyAdmin (http://localhost/phpmyadmin/).
  - Create a new database named parameter_analyser.
  - Import the provided SQL file (database.sql) from the project directory.
5. **Run the project in a web browser:**
  ```sh
  http://localhost/parameter-analyser/index.php
  ```
